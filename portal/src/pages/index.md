# Blockallisto documentation

Blockallisto is a crowdfunding platform for tokenized real-world assets,
built on the Stellar network. It is a working prototype running on the
Stellar testnet.

- [Introduction](./docs/intro) - what the platform does
- [Getting started](./docs/getting-started) - try the testnet demo
- [Architecture](./docs/architecture) - how the pieces fit together

:::info Testnet prototype
Everything described here runs on the Stellar testnet with test assets.
No real money is involved.
:::
