# Introduction

Blockallisto is a crowdfunding platform for tokenized real-world assets
(RWA) - real estate, renewable energy and other tangible projects - built on
the Stellar network using Soroban smart contracts.

The platform lets issuers present funding campaigns and lets investors back
them directly from a Stellar wallet. Campaign terms are enforced by the
smart contract rather than by platform promises.

**Status: prototype on the Stellar testnet.** Campaigns, balances and
payouts use test assets only; no real funds flow through the platform.

A public demo deployment is available at
[blockallisto-demo.onrender.com](https://blockallisto-demo.onrender.com).

## What this documentation covers

- **Getting started** - trying the demo with a Stellar wallet
- **Architecture** - the main components and how they interact
- **Smart contract** - the funding rules enforced on-chain
- **Testing and deployment** - how the project is verified and shipped
