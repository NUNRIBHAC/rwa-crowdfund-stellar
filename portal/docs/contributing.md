# Contributing

Blockallisto is currently a private, all-rights-reserved project.
The source repository is not public, and contributions are by invitation.

## Ground rules

- All committed content - code, comments and documentation - is written in
  English.
- Every change must pass the full CI suite: backend, frontend and contract
  tests, plus the contract build.
- Translations for the user interface are managed in a separate translation system;
  do not hand-edit exported locale files.
