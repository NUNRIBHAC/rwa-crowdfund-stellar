# Environments and infrastructure

|              | Demo (canonical)                       | Staging                                    |
| ------------ | -------------------------------------- | ------------------------------------------ |
| URL          | https://blockallisto-demo.onrender.com | https://rwa-crowdfund-staging.onrender.com |
| Purpose      | Public testnet prototype               | Load/realistic testing before merge        |
| Deploys from | `main` (auto-deploy)                   | `feature/community-platform` (auto-deploy) |
| Database     | own Neon Postgres                      | own Neon Postgres                          |
| Contract     | own testnet instance                   | own testnet instance                       |

- Hosting: Render free tier (web services), Node 24. Free services sleep
  when idle; expect ~30s cold starts.
- The old `rwa-crowdfund-demo.onrender.com` hostname still serves the demo.
- `/.well-known/stellar.toml` and `/sitemap.xml` are generated by the
  backend.
- Self-hosted tooling on the Oracle Cloud VM: Weblate (translations),
  Uptime Kuma (monitoring), nightly encrypted backups of both Neon
  databases.
- GitHub: private repo `NUNRIBHAC/rwa-crowdfund-stellar`, Free plan (no
  private-repo branch protection; accepted). CI on GitHub Actions runs
  backend, frontend and Rust tests plus the contract build.
