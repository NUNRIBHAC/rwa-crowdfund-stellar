# Environments and infrastructure

|              | Demo (canonical)                  | Staging                                     |
| ------------ | --------------------------------- | ------------------------------------------- |
| URL          | https://demo.92-5-187-71.sslip.io | https://staging.92-5-187-71.sslip.io        |
| Purpose      | Public testnet prototype          | Load/realistic testing before merge         |
| Deploys from | `main`, manual operator deploy    | `feature/community-platform`, manual deploy |
| Database     | own Neon Postgres                 | own Neon Postgres                           |
| Contract     | own testnet instance              | own testnet instance                        |

- Hosting: one Oracle Cloud VM, Node 24, each environment in its own container.
  `render.yaml` is reference-only; its Render service is suspended.
- Neither environment deploys automatically. An operator builds an image from a
  pinned commit and recreates the container. A merge to `main` is not a release.
- Migrated from Render to an Oracle VM in November 2026; the onrender.com hostnames (including the old `rwa-crowdfund-demo.onrender.com`) are suspended and no longer serve.
- `/.well-known/stellar.toml` and `/sitemap.xml` are generated by the
  backend.
- Self-hosted tooling on the Oracle Cloud VM: Weblate (translations),
  Uptime Kuma (monitoring), nightly encrypted backups of both Neon
  databases.
- GitHub: private repo `NUNRIBHAC/rwa-crowdfund-stellar`, Free plan (no
  private-repo branch protection; accepted). CI on GitHub Actions runs
  backend, frontend and Rust tests plus the contract build.
