## Notes

- The supplied file's 50 `<loc>` entries match the live `https://www.invesdor.com/sitemap.xml` retrieved 2026-10-30 (WET): both contain exactly the same 50 URLs, verified by exact set comparison.
- The sitemap carries `<loc>` fields only, with no `lastmod`, `changefreq` or `priority` values, so no per-URL dates exist to preserve.
- URLs are grouped by site section following the classification used in `dagobertinvest-sitemap.md`; the `#` column keeps each URL's position in the supplied file, and every supplied URL is preserved verbatim (including the `newletter-companies` slug).
- Unlike dagobertinvest, Invesdor's sitemap does not enumerate individual investment rounds; per-round coverage would require crawling `/rounds`, which is not sitemap data and was not performed.
