# Approved design refinement acceptance

Current design reference: https://files.instinct.com/34lhl7msqnbq-blockallisto-brand-guide
Revision read: generation 17, published 3 November 2026. Older ZIP assets are
archived and do not override the current guide.

This checklist tracks implementation requirements, not completed verification.

- Preserve the exact slogan "Real assets. Shared possibilities."
- Preserve the 100-block campaign scale and 1% unit. The 3x3 illustration is
  brand/About symbolism, not campaign data.
- Use approved Paper #F7F6FE and Indigo pale #C7C9F9 tokens. Retain stronger
  text/boundary colors wherever needed for contrast.
- Navy/light changes apply to navigation and footer; bodies/cards stay light.
- All existing/future demo cards and detail pages need loaded photos and visible
  illustrative captions. Actual issuer publication needs issuer image/source/
  rights review, not an unrelated illustrative fallback.
- Restore original footer horizontal balance while retaining 44px targets; no
  exact 271px height claim. Test all 11 locales and both themes.
- Cards use the guide's consistent image/name/purpose/funding/deadline/grid/
  status/action order. Do not invent missing financial or issuer information.
- Mobile summary precedes the photo; compact facts keep exact numeric values.
- Issuer claims and funding records are distinct. Missing data is not zero.
- Contribution preview uses decimal-safe 7-place units. The approved 250 USDC
  example at 66,000/100,000 yields 0.25% and 66.25%. Display rounding must be
  disclosed and cap rules must match the actual contract. Preview is not a
  submission, signature, pending transaction or ownership grant.
- Preview additions use pattern/outline as well as color. Refunds remain
  contributor-signed and conditional, never automatic or guaranteed.
- Script-aware font stacks need source/license checks and rendered acceptance.
  Arabic text is RTL within existing LTR layout and financial geometry.
- Test 320/390/1280 widths, all locales, both navigation/footer themes, keyboard,
  200% text scaling and reduced motion. A screenshot is not native/legal review.
